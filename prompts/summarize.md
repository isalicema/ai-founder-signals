# 摘要生成 Prompt

> 通过准入判定后调用，输入为全文/字幕。模型：Haiku 级。
> 产物直接进 feed 卡片——用途是**帮你决定要不要点开原文**，不是替代阅读。

---

为这场 AI 创始人访谈生成 feed 卡片信息。

## 🚫 硬约束（违反即不可用）

1. **禁止输出任何引号包裹的原话。** 不要写 "他说：'……'"，不要摘录原句。只写概括。
   —— 这个系统不保存原文，无法核验引文，所以一句都不允许编造的空间。
2. **`summary` 必须使用简体中文。** 即使标题、正文或字幕是英文，也要用中文概括；
   DHH、Agent、ARR 等人名、品牌名、产品名和专有术语可保留英文。
3. `tags` 只能从下面的固定主题里选，**不允许自创**。
4. 摘要写事实与判断，不写"本文精彩纷呈""值得一读"这类空话。

## 一级主题（tags 只能从这 15 个里选 3-5 个）

```
基础模型 / Agent / AI 编程 / AI 硬件 / 机器人
消费级 AI / 企业服务
开源 / 安全与治理
产品与用户 / 商业模式 / 增长与销售 / 市场与竞争 / 组织与人才
创业历程
```

### 选标签的原则（定稿）

- **选 3-5 个，不是把能沾边的全贴上。** 按访谈篇幅和重要性排序，不按标题里出现了几个关键词。
- 「基础模型 / Agent / AI 编程 / AI 硬件 / 机器人」回答**在做哪类技术或产品**。
- 「消费级 AI / 企业服务」回答**主要服务谁**；一场既谈 C 端也谈 B 端时可以并存。
- 「产品与用户 / 商业模式 / 增长与销售 / 市场与竞争 / 组织与人才」回答**公司如何做成这件事**。
- 「开源 / 安全与治理」是跨品类的关键选择，**只有访谈有实质讨论时才选**——公司用了开源模型不等于该贴「开源」。
- 「创业历程」**只在起步、转型、失败或个人经历占明显篇幅时用**。每场访谈都来自创始人，不等于每场都该贴这个。
- **地区不进 tags**（用 source.country 筛选）。只有出海、本地化、地缘竞争才用「市场与竞争」。
- **融资不是独立主题**。创始人讨论融资策略、现金流、资本效率时用「商业模式」。

## summary 写法（150-250 个汉字，统一使用简体中文）

按这个顺序压缩，不要分点、不要小标题，写成一段：

1. 这场访谈的核心话题是什么；
2. 创始人给出的最具体的 1-2 个判断或做法（**要具体**：说了什么数字、什么取舍、什么反直觉的选择）；
3. 如果有明显的 PR 叙事成分或未经验证的预测，用一个短句点出来。

**判断标准**：读完这 200 字，应该能回答"我要不要花 40 分钟看原文"。
写得笼统（"探讨了 Agent 的未来"）等于没写。

## 输出（严格 JSON，无其它文字）

```json
{
  "summary": "……",
  "tags": ["Agent", "商业模式"],
  "persons": ["受访者姓名，用文中出现的写法"],
  "companies": ["公司名"]
}
```
