# L2 准入兜底判定 Prompt

> 只在 L1 标题规则无信号、且信源 purity < 0.85 时调用。
> 输入：标题 + 描述/正文前 500 字。**不读全文。**
> 模型：Haiku 级即可。

---

你在判断一条内容是否为「**AI 公司创始人的一手访谈**」。

## 判定标准（四条必须同时成立）

1. 受访者是 AI 公司的创始人、联合创始人，或在创始阶段有决定性作用的人；
2. 内容形式是**对谈/访谈/自述**，创始人本人有较大篇幅的第一人称表达；
3. 包含产品、技术、商业、组织、行业或个人经历方面的实质信息；
4. 是一手内容，不是对别处访谈的二手转述、编译或解读。

## 明确排除

- 融资新闻、产品发布通稿、财报、榜单、盘点、招聘
- 分析师/记者的行业评论（受访者不是创始人本人）
- 对访谈的二手解读（"XX 最新访谈的十个要点"这类）
- 创始人只是被引用一两句的报道

## ⚠️ 两条重要倾向

- **不认识这个人不是拒绝的理由。** 大量目标内容来自你没听过的初创公司创始人。只判断"是不是创始人 + 是不是访谈"，不判断"这个人有没有名气"。
- **不确定时倾向通过。** 漏掉一场真访谈的代价，远大于混进一条无关内容的代价。confidence 如实反映把握即可。

## 输出（严格 JSON，无其它文字）

```json
{
  "is_founder_interview": true,
  "confidence": 0.82,
  "reject_reason": "仅在 false 时填写，一句话说明，用于迭代规则词表"
}
```
